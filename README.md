# Accenture Java Full Stack Engineering (ACC-Java-FS)

Welcome to the comprehensive **Accenture Java Full Stack Engineering** repository. This repository houses source code, hands-on demonstrations, lab activities, assignments, and architectural designs covering enterprise Java full-stack development, modern microservices, cloud fundamentals, DevOps, and AI-driven development.

---

## 📌 Repository Overview

This curriculum spans from core language engineering principles and object-oriented design to modern enterprise cloud-native systems, event-driven architectures, and generative AI integrations.

## 📚 Curriculum & Module Breakdown

| Module | Title | Key Topics & Highlights |
|:---:|:---|:---|
| **01** | **Problem Solving & Java programming** | Core Java fundamentals, Datatypes, Control Flow, OOP principles, Exception Handling, Multithreading, Collections Framework, Data Structures, and debugging best practices. |
| **02** | **Java LTS Features** | Modern features across Java 8, 11, and 17 (Lambdas, Streams API, Records, Sealed Classes, Pattern Matching, Switch Expressions). |
| **03** | **Unit Testing with JUnit 5** | Unit testing with JUnit 5, Assertions, Parameterized tests, Test-Driven Development (TDD) lifecycle, and mocking patterns. |
| **04** | **Performance Monitoring** | Memory management, JVM profiling, Garbage Collection monitoring, bottlenecks detection, and optimization. |
| **05** | **Architecture and Design Patterns** | SOLID principles, Clean Architecture, and GoF patterns (Creational, Structural, and Behavioral patterns). |
| **06** | **Database and ORM** | Relational data access with JDBC, Hibernate, JPA entity lifecycles, JPQL queries, Transactions, and NoSQL with MongoDB. |
| **07** | **Spring Stack Essentials** | Inversion of Control (IoC), Dependency Injection (DI), Spring Core configuration (XML & JavaConfig), and Spring Test framework. |
| **08** | **Spring Web and Data** | Spring MVC, Spring Data JPA, Custom Repositories, Spring Form Handling, Spring REST APIs, and Batch Processing. |
| **09** | **Microservices with Spring Boot & DDD** | Domain-Driven Design (DDD), Spring Boot auto-configuration, Spring Batch pipelines, and Aspect-Oriented Programming (AOP). |
| **10** | **Microservices Design Pattern with Spring Cloud** | Service Discovery with Eureka, Client-side Load Balancing, Circuit Breakers & Resilience4j, API Gateway, and Distributed Communications. |
| **11** | **Application Security** | Spring Security 6.x, Authentication/Authorization, Role-Based Access Control, JWT, Password Encryption, and Feign Client Security. |
| **12** | **Front-End with React** | HTML5, CSS3, ES6 JavaScript, React components, state management, hooks, and REST API integration with Spring Boot backends. |
| **13** | **Cloud Fundamentals** | Cloud computing architectures, SaaS/PaaS/IaaS models, high-availability deployments, and cloud native concepts. |
| **14** | **Build Automation** | Build lifecycle management, Maven dependency management, plugins, profiles, and packaging strategies. |
| **15** | **Process Automation** | Continuous integration concepts, automated testing hooks, and pipeline workflows. |
| **16** | **Code Quality** | Static code analysis, SonarQube integration, code smells reduction, vulnerability scanning, and technical debt management. |
| **17** | **Infrastructure as Code with Terraform** | Declarative cloud infrastructure provisioning, state management, modules, and provider configurations. |
| **18** | **Containerization** | Docker container basics, Dockerfiles, multi-stage builds, container networking, and Docker Compose environments. |
| **20** | **AI-Driven Development** | AI application integration, Spring AI framework, LLM prompts orchestration, and generative AI demo workflows. |

## 🛠️ Prerequisites & Tech Stack

- **Languages**: Java 17 / 21 LTS, JavaScript (ES6+), SQL, HCL (Terraform)
- **Frameworks & Libraries**: Spring Boot 3.x, Spring Cloud, Spring Data JPA, Spring Security, Hibernate, React.js
- **Build & Dependency Tools**: Apache Maven, Gradle, npm / yarn
- **Testing**: JUnit 5, Mockito, AssertJ
- **Databases**: MySQL, PostgreSQL, MongoDB, H2 In-Memory DB
- **Cloud & DevOps**: Docker, Terraform, SonarQube, Git / GitHub
- **Storage**: Git LFS enabled for large demo datasets and distribution archives

## 🚀 Getting Started

### 1. Clone the Repository
```bash
git clone https://github.com/rahuljenaa/ACC-Java-FS.git
cd ACC-Java-FS
```

### 2. Pull Git LFS Objects
This repository utilizes Git LFS for demo archives and binary assets:
```bash
git lfs install
git lfs pull
```

### 3. Build a Spring Boot Module
Navigate to any module directory and run:
```bash
mvn clean install
```
