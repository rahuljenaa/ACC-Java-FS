ImprovedNamingStrategy - Generating underScodes (Snake Naming Conventions)

Hibernate 4/5 provides two different naming strategies for use with 
Hibernate entities: a
An Implicit Naming Strategy and a Physical Naming Strategy.

The ImplicitNamingStrategy governs how Hibernate derives a logical name 
from our Java class and property names.

ImplicitNamingStrategy --
	Customer -> Customer
	firstName -> firstname
	lastName -> lastname
	emailAddress -> emailaddress
	
PhysicalNamingStrategy --
	Customer -> customer
	firstName -> first_name
	lastName -> last_name
	emailAddress -> email_Address
